## 📌 Sobre o projeto

O **Relapse/AIO** é descrito como um método que combina uma cadeia de exploits **WebKit + Kernel** para PS5. A página é aberta pelo navegador do console e, quando o processo funciona corretamente, o menu de payloads aparece na tela.

## 🧩 Compatibilidade

| Item | Detalhes |
|---|---|
| **Firmwares informados** | 7.00 até 13.60, incluindo versões intermediárias |
| **Firmwares sem suporte indicado** | 10.60 e 11.40 |
| **Consoles** | Retail e Testkit |
| **Devkit** | Requer a versão específica **Relapse-Dev** |

> ⚠️ **Atenção:** segundo as informações deste README, as versões 10.60 e 11.40 ficaram de fora por falta de módulos necessários para obter os offsets usados pelo exploit. Confirme sempre a compatibilidade exata antes de tentar qualquer procedimento.

## ⚙️ Como funciona

1. Abra a página do método no navegador do PS5.
2. Aguarde a execução do processo.
3. Se a execução for bem-sucedida, o menu de payloads deverá aparecer na tela.
4. O envio dos arquivos ELF é descrito como feito pelo próprio console, sem servidor externo para essa etapa.

*Estes passos são um resumo descritivo das informações disponíveis; o resultado pode variar conforme a versão do sistema e os arquivos utilizados.*

## 🗂️ Sobre o `elf.html`

O arquivo `elf.html` é apresentado como um menu separado para consoles que **já estão desbloqueados**.

- Precisa de um servidor compatível com execução de código e acesso ao console.
- **Não funciona no GitHub Pages**, conforme a descrição original.

## 🛡️ Avisos importantes

- Verifique a versão exata do firmware do console antes de prosseguir.
- Utilize apenas arquivos de fontes em que você confia.
- Faça sua própria verificação das instruções e dos requisitos publicados pelos desenvolvedores.
- Este README é informativo e não garante que o método funcione em todos os consoles.
